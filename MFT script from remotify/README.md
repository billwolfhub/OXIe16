# MFT script

The original Midi Fighter Twister Ableton script this project was ported from, generated with Remotify / Control Surface Studio (script name `css_bw43`).

- `css_bw43/css_bw43.json` is the readable configuration: a 16-track mixer with volume on knobs 1-16 and mute on buttons 1-16 (a second send bank was defined but unused).
- `css_bw43/css_bw43.py` is about 4,600 lines of generated boilerplate.

Kept for reference only. The e16 script in `e16_ableton/` does not use any of it.
